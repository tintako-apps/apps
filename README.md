# Apps for E Ink devices

A collection of lightweight, minimalist, and privacy-focused applications made for E Ink devices.

| App | What it does |
|---|---|
| [Radio](https://github.com/tintako-apps/radio) | Internet radio and podcasts |
| [News](https://github.com/tintako-apps/news) | A calm news reader |
| [Work](https://github.com/tintako-apps/work) | Mail, calendar, notes and to-do lists |
| [Wallet](https://github.com/tintako-apps/wallet) | Offline cards with barcodes |
| [Books](https://github.com/tintako-apps/books) | Offline e-book reader |
| [Sudoku](https://github.com/tintako-apps/sudoku) | A calm offline sudoku |
| [Browser](https://github.com/tintako-apps/browser) | A web browser with reader mode (beta) |
| [Snake](https://github.com/tintako-apps/snake) | The classic snake game, made for E Ink |

Download each app's APK from its Releases page and install it on your E Ink device.
